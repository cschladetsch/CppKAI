# EXternals

This folder contains optional external dependancies for a KAI build.

* **ENet**. Networking.
* **imgui**. Graphical UI.
* **rang**. Cross-platform console coloring.
* **CppLmmModelStore**. Local model-store utilities for optional LLM features. KAI uses it to manage models under `~/.cache/deepseek/models` by default.
