Continuation Mobility

A system-level explanation of the single-file Rho demo at Test/Language/TestRho/Scripts/ContinuationMobilityDemo.rho. It shows ten agents, four logical hosts, Pi-guided routing, periodic snapshots, load balancing, and a forced failure on NodeB at tick 60 that restores three agents onto NodeD.

Agents move
Autonomous patrol and Pi planning change region placement over time.
State persists
Snapshots capture each agent before failure and drive recovery.
Load balances
The busiest host sheds agents to the least loaded host every 25 ticks.
Recovery is deterministic
Agents 1, 2, and 3 are forced onto NodeB before failure so the drill stays readable.
